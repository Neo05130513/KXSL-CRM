# 知兔-快享市场地图 产品需求文档

## 1. 产品定位

知兔-快享市场地图是一款面向快递三轮车租赁老板个人使用的轻量市场 CRM 与地图拜访工具。产品帮助用户沉淀郑州市快递站点资源，查看现有客户分布，规划日常拜访路线，并通过语音与 AI 整理能力快速生成拜访记录和后续跟进任务。

## 2. 使用对象

- 当前阶段：老板本人单人使用
- 典型场景：市场拜访、客户复访、站点信息采集、租赁机会跟进、合同到期提醒
- 暂不支持：多人组织、复杂权限、业务员绩效、财务结算审批

## 3. 核心目标

- 打开软件即可看到郑州客户与目标站点分布
- 根据站点位置、客户状态、跟进时间规划拜访路径
- 拜访结束后用语音输入，自动整理为结构化客户信息
- 形成“地图找点 -> 路线拜访 -> 语音记录 -> 跟进提醒”的闭环
- 帮助老板判断哪些区域空白、哪些客户值得重点推进

## 4. 一期范围 MVP

### 4.1 地图首页

地图首页作为默认入口，展示郑州市快递站点分布。

主要能力：
- 显示全部站点点位
- 按状态筛选站点：已合作、有意向、未拜访、暂不合作、重点客户
- 查看站点简要信息：名称、品牌、区域、车辆数、意向程度、下次跟进
- 选择多个站点生成今日拜访路线
- 显示路线顺序、预计里程、预计耗时

站点颜色：
- 绿色：已合作
- 黄色：有意向
- 红色：未拜访
- 灰色：暂不合作
- 蓝色：重点客户

### 4.2 站点档案

每个站点维护完整客户资料。

字段：
- 站点名称
- 快递品牌
- 行政区
- 详细地址
- 经纬度
- 联系人
- 手机号
- 当前车辆数
- 竞品车辆数
- 预计可租车辆数
- 合作状态
- 意向等级
- 关注点
- 上次拜访时间
- 下次跟进时间
- 备注

### 4.3 拜访记录

每次拜访后生成一条记录。

字段：
- 关联站点
- 拜访时间
- 拜访结果
- 沟通摘要
- 客户需求
- 客户顾虑
- 报价信息
- 竞品情况
- 下次动作
- 下次跟进时间

### 4.4 AI 拜访助手

用户拜访结束后，通过语音或文本输入一段口语化内容，系统自动整理为结构化记录。

处理流程：
1. 浏览器语音识别将语音转文字
2. 大模型或本地规则从文字中提取字段
3. 生成结构化拜访记录和跟进建议
4. 用户在确认页修改
5. 保存到站点档案、拜访记录和提醒

一期演示版：
- 支持手动输入拜访口述
- 支持浏览器语音识别
- 支持模拟 AI 提取字段
- 预留大模型接口调用位置

后续正式版：
- 接入语音转文字服务
- 接入大模型结构化抽取
- 支持自动生成 JSON 入库
- 支持根据历史记录生成跟进话术

### 4.5 今日拜访

根据站点状态、下次跟进时间和区域距离生成拜访建议。

一期推荐规则：
- 优先今日应跟进站点
- 优先高意向客户
- 优先重点客户
- 同一区域集中拜访
- 未拜访目标站点作为补充

### 4.6 经营看板

展示经营与市场覆盖概况。

指标：
- 总站点数
- 已合作客户数
- 意向客户数
- 未拜访站点数
- 车辆出租数
- 潜在车辆需求数
- 本月拜访数
- 即将跟进客户数
- 各行政区站点分布
- 各快递品牌分布

## 5. 二期能力

- 手机端定位当前位置

- 车辆租赁台账

- 多员工协作与权限

## 8. 关键业务闭环

### 新站点开发

发现站点 -> 地图新增点位 -> 标记未拜访 -> 加入拜访计划 -> 拜访后语音记录 -> 标记意向等级 -> 设置下次跟进。

### 意向客户推进

筛选有意向客户 -> 查看历史沟通 -> 规划路线 -> 拜访报价 -> AI 整理顾虑和需求 -> 生成下次动作。

### 老客户维护

查看已合作客户 -> 合同/复访提醒 -> 拜访了解车辆使用情况 -> 记录增租机会和服务问题 -> 形成续租跟进。

## 9. AI 结构化输出建议

大模型输出 JSON 字段：

```json
{
  "siteName": "站点名称",
  "brand": "快递品牌",
  "contactName": "联系人",
  "phone": "手机号",
  "currentVehicles": 0,
  "competitorVehicles": 0,
  "potentialVehicles": 0,
  "intentLevel": "高/中/低",
  "visitResult": "有意向/报价中/已成交/拒绝/无人",
  "needs": "客户需求",
  "concerns": ["价格", "维修响应"],
  "quote": "报价信息",
  "nextAction": "下次动作",
  "nextFollowDate": "YYYY-MM-DD",
  "summary": "拜访摘要"
}
```

## 10. 非功能需求

- 单人使用，操作要快，移动端优先适配
- 拜访记录录入时间控制在 1 分钟内
- 地图点位加载流畅
- 数据支持导出，避免客户资产锁死
- AI 生成内容必须人工确认后入库
- 后续可平滑升级到多人版本

## 11. 一期验收标准

- 可以看到地图式站点分布
- 可以筛选不同客户状态
- 可以选择站点生成拜访顺序
- 可以新增拜访口述并整理成结构化信息
- 可以保存拜访记录
- 可以查看看板指标
- 可以在手机浏览器中正常使用核心流程
