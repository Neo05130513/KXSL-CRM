# 服务器部署与多端同步方案

## 推荐形态

本项目优先按“服务器网页应用 + PWA 安装体验”交付。手机和电脑访问同一个 HTTPS 地址，登录同一套账号，业务数据写入服务器上的同一个 `data/app.db`，因此天然同步。

不建议第一阶段直接封装安装包。安装包只能改变入口形态，不能解决数据同步；同步仍然需要服务器、账号、数据库和备份。

## 部署步骤

1. 在服务器安装 Python 3、Node.js 和 Git。
2. 上传或拉取本项目到服务器目录，例如 `/opt/kxsl-crm`。
3. 复制 `.env.example` 为 `.env`，修改管理员密码、高德 Key 和端口。
4. 执行 `npm run init-db` 初始化数据库。
5. 执行 `npm start` 验证服务能在 `http://服务器IP:4173/` 打开。
6. 用 Nginx 或服务器面板把域名反向代理到 `127.0.0.1:4173`。
7. 给域名开启 HTTPS。
8. HTTPS 可用后，把 `.env` 中 `KXSL_COOKIE_SECURE=1` 保持开启。
9. 手机和电脑都使用同一个域名登录。
10. 手机浏览器选择“添加到主屏幕”，即可按 PWA 方式使用。
11. 执行部署自检脚本确认健康检查、PWA、登录保护和敏感文件保护都通过。

## 关键环境变量

```bash
KXSL_HOST=0.0.0.0
KXSL_PORT=4173
KXSL_ADMIN_USER=admin
KXSL_ADMIN_PASSWORD=replace-with-a-strong-password
KXSL_SESSION_DAYS=14
KXSL_COOKIE_SECURE=1
AMAP_KEY=replace-with-your-amap-web-service-key
```

`KXSL_ADMIN_PASSWORD` 在已有默认管理员账号时也会生效，可用于把本地默认密码切换为生产密码。正式交付前不要继续使用 `admin / admin123`。

## 同步和数据边界

- 本机直接运行时，手机和电脑只有访问这台机器的同一个地址才会同步。
- 部署到服务器后，所有设备访问同一个域名，数据同步到服务器数据库。
- 当前 SQLite 适合小团队和单业务点使用。
- 如果后续出现多人高并发、分公司数据隔离、复杂审计或移动端离线写入，再升级 PostgreSQL/MySQL。

## 备份要求

- `data/app.db` 是核心数据库。
- `data/backups/` 保存手动备份和导入前自动备份。
- 建议每天至少做一次服务器级文件备份。
- 每次大批量导入前，先在“数据”页执行数据库备份。
- 迁移服务器时，复制项目代码、`.env`、`data/app.db` 和 `data/backups/`。

命令行备份：

```bash
python server.py --backup scheduled
```

Linux 定时备份示例见：

```text
deploy/cron-kxsl-crm-backup.example
```

Windows 计划任务示例见：

```text
deploy/windows-scheduled-backup.example.ps1
```

## 部署自检

服务启动后，在本机或服务器执行：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/deploy_check.ps1 -BaseUrl http://127.0.0.1:4173
```

如果已经绑定域名，也可以把 `BaseUrl` 改为正式 HTTPS 地址：

```powershell
powershell -ExecutionPolicy Bypass -File ./scripts/deploy_check.ps1 -BaseUrl https://crm.example.com
```

脚本会检查首页、健康检查、未登录接口保护、PWA 文件、图标、敏感文件不可访问。

## 验收标准

- 电脑浏览器可以通过 HTTPS 域名登录。
- 手机浏览器可以通过同一域名登录。
- 电脑新增站点后，手机刷新可看到同一条数据。
- 手机保存拜访记录后，电脑刷新可看到同一条记录。
- `/api/health` 返回 `status: ok`。
- 未登录访问 `/api/bootstrap` 返回 401。
- `/manifest.webmanifest` 返回 PWA manifest。
- `/service-worker.js` 可以正常注册。
- 请求 `/.env`、`/data/app.db`、`/.git/config` 不应返回文件内容。
