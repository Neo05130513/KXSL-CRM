# 知兔-快享市场地图正式交付验收清单

## 基础访问

- 使用管理员账号登录后才能访问业务接口。
- 未登录访问 `/api/bootstrap` 返回 401。
- 老板/管理员可以在“数据”页开通业务员、只读查看或管理员账号。
- 非管理员账号不能开通新账号。
- `KXSL_HOST=0.0.0.0` 时，同一局域网手机可以访问服务地址。
- 生产环境已修改 `KXSL_ADMIN_USER` 和 `KXSL_ADMIN_PASSWORD`。
- 通过 HTTPS 域名访问时，`.env` 中启用 `KXSL_COOKIE_SECURE=1`。
- 生产服务不在终端输出管理员密码。
- `/api/health` 返回 `status: ok`。

## 客户与拜访

- 可以在“发现”页按城市、区县和快递品牌搜索高德 POI 站点线索。
- 可以勾选候选站点并导入为未拜访目标站点。
- 重复站点不会被重复导入。
- 可以新增、编辑、删除站点。
- 可以按状态、站点、品牌、区域、联系人搜索。
- 可以在地图上查看站点点位，不同快递公司使用不同颜色和形状。
- 可以把站点加入今日拜访路线。
- 可以在拜访助手中整理口述内容并保存拜访记录。
- 保存拜访记录后，站点的车辆数、意向等级、关注点和下次跟进日期同步更新。

## 跟进工作台

- 可以看到逾期未跟进站点。
- 可以看到今日应跟进站点。
- 可以看到 7 天内即将跟进站点。
- 可以看到未设置下次跟进的站点。
- 可以把应跟进站点批量加入今日路线。
- 可以将单个站点标记为已跟进并顺延 7 天。

## 经营资产

- 可以新增车辆台账。
- 可以记录车辆状态：空闲、在租、维修、报废。
- 可以新增合同并记录开始日期、到期日期、车辆数、月租和押金。
- 可以看到 30 天内即将到期合同。
- 可以新增应收租金记录。
- 可以把应收租金标记为已收。
- 可以新增售后工单。
- 可以把售后工单标记为已解决。

## 数据安全

- 可以手动创建数据库备份。
- 导入 JSON 前会自动创建数据库备份。
- 可以导出完整 JSON 数据。
- 可以导出拜访记录 CSV。
- 可以通过 `python server.py --backup scheduled` 创建命令行数据库备份。
- 已配置每日定时备份方案。
- `data/app.db` 和 `data/backups/` 不纳入 Git 提交。
- 请求 `/.env`、`/data/app.db`、`/.git/config` 不返回文件内容。

## 多端同步与 PWA

- 电脑端和手机端访问同一个服务器域名。
- 电脑端新增站点后，手机端刷新可以看到同一条数据。
- 手机端保存拜访记录后，电脑端刷新可以看到同一条记录。
- `/manifest.webmanifest` 返回应用清单。
- `/service-worker.js` 返回 JavaScript 且可以注册。
- 手机浏览器可将系统添加到主屏幕。
